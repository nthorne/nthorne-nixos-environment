---
name: grill-me
description: Stress-test a plan or design by interviewing the user about its assumptions and decisions. Use when the user asks to challenge the plan itself, not to test their understanding of an existing artifact (use `quiz-me` for that).
---

Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one. For each question, provide your recommended answer.

If a question can be answered by exploring the codebase, explore the codebase instead.

Use this skill to challenge the plan or design itself. Use `quiz-me` when the user wants to check their understanding of what an existing artifact says.

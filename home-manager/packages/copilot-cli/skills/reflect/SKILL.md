# Reflect

## Invocation

- On an explicit request, pause the current task and reassess it; do not continue implementation
  alongside the reflection.
- For a long or stuck thread without an explicit request, offer reflection first. Wait for consent
  before pausing work or producing the assessment.
- If there is no meaningful context to reassess, ask one focused question about the target.

## Review

Revisit the conversation from its original goal through the current state. Check current artifacts
when available. Consider only relevant dimensions:

1. **Goal and drift:** What was the goal? Has work moved away from it, and why?
2. **Gaps:** Which assumptions, constraints, stakeholders, or alternatives remain unchecked?
3. **Framing:** Are we solving the right problem? Is there a simpler or more valuable path?
4. **Bias:** Look for confirmation, sunk-cost, anchoring, complexity, or recency bias. Name one
   only when specific evidence supports it.
5. **Alignment:** Does the current direction serve the user's goals and priorities?

Use concrete evidence from the conversation or artifacts. Separate verified facts from unknowns.
Do not invent problems or offer reassurance without reasons.

## Response

Give a concise, natural assessment. Cover relevant dimensions without forcing a five-part report.
End with one specific recommendation:

- **Continue** — explain why current direction is sound.
- **Pivot to X** — name what evidence supports changing.
- **Pause for X** — state which answer is needed and what risk it resolves.

After the assessment, stop and wait for the user's direction.
